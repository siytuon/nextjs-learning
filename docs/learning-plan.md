# 8週間の学習方針

計画は固定せず、理解度・興味・1回30分という負荷に合わせて更新する。

## 現在の方針

- 今週: 2選手の主要成績を正規化し、CSSの横棒グラフで可視化した
- 現在: 第5回「グラフによる可視化」が完了
- 公開方法: 1〜6週目は公開済みのGitHub Pages（`https://siytuon.github.io/nextjs-learning/`）を使い、PC・iPhoneから同じ成果を確認する
- 次回: TypeScriptの型とReactのstateを、これまでの実装を使って整理する
- 次の段階: 並べ替え・絞り込み・比較・集計・可視化を、画面の変化を確認しながら追加する
- 後半: コンポーネント分割、型、状態管理、ページ構成、データ取得を実装に結び付けて整理する
- 完成後: 推し活情報、株式分析、AI連携のいずれへ発展させるか選ぶ

## 8週間の目安

1. 起動、画面構成、実データのCSV表示
2. 検索、並べ替え、絞り込み
3. 選手詳細とコンポーネント分割
4. 選択状態のコンポーネント間同期、選手比較と集計
5. グラフによる可視化
6. TypeScriptの型とReactのstateを整理
7. Next.jsのページ構成とデータ取得、サーバー機能に対応したホスティングへの移行
8. 仕上げ、振り返り、次の題材選択
